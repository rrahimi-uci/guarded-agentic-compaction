have labels for every assigned calibration group (92 each). The audit found no
family-window omission inside those selected splits. It confirms an earlier selection

### Separately budgeted adaptive SQL pilot

The author subsequently authorized a $300 total model/API cap. The
[pilot protocol](../../../experiments/adaptive_compiler_pilot/README.md) and
[frozen cohort/settings](../../results/adaptive_compiler_pilot/seal.json) define
36 corrected BIRD questions across nine databases, with 108 scheduled episodes.
The [retained report](../../results/adaptive_compiler_pilot/report.json) distinguishes
attempt status, official-style set execution accuracy, stronger shape/bag
diagnostics, candidate validity, and total generation/execution accounting.

This is a new common-endpoint adaptive agent, manual prefetch, and an Agent JIT
SQL adaptation. It is neither a native browser reproduction nor the requested
full-GAC versus simpler-admission experiment. The first operational version failed
because its endpoint/model combination rejected reasoning-enabled function calls;
its seal, attempts and spending remain retained separately. The amended version
uses reasoning `none` for all arms. Both versions are exploratory and all pilot IDs
remain excluded from future calibration/test.

The experimental gate has not changed: do not spend the remaining campaign budget
on confirmatory execution until the live comparator semantics, candidate set,
calibration population, sampling unit, quality margin, multiplicity and fixed test
size are independently specified. These pilot outcomes do not certify quality,
learned gating, lifecycle benefit, or acceptance. The current manuscript's
quantitative claims remain on their original evidence until a separate integration
explicitly names any completed pilot result and its limitations.

### Provider-free follow-up to the SQL pilot

The [prefix/comparator validation report](../../results/adaptive_prefix_validation/REPORT.md)
now verifies execution parity for all 36 selected SQL programs against the pinned
upstream executor under identical RPC responses. This is adapter validation, not
a new answer-quality score or native browser reproduction. The old pilot scores
remain unchanged.

A separately recorded one-call development setting synthesizes `list_tables()`
from 27 training traces and passes nine development replays. All 36 baseline

limitations documented explicitly. Confirmatory execution remains a no-go pending
the protocol and evidence conditions in that report. No additional API spending
or manuscript numerical-claim changes were made by this follow-up.


### Interrupted AppWorld adaptive pilot and evaluator repair

The [AppWorld development report](../../results/appworld_adaptive_viability/REPORT.md)
retains a fixed 12-scenario, two-arm attempt. The compatible dependency image passed
36 reference/negative controls before execution. A later exact-path audit found that
reference execution persisted state automatically while direct model API calls did
not. The original agent grades are invalid. Execution stopped with nine completed,
one interrupted and fourteen unstarted dispositions; every provider charge remains
accounted for. The original sealed code and evidence are retained.

The corrected persistence boundary passes three direct-agent-path controls. A
known-correct sequence changes from 0/6 to 6/6 grading assertions with identical API
responses. Provider-free regrades of all nine completed histories preserve exact
context/API-result parity and produce no successes. They are diagnostic repairs,
not fresh adaptive trials, population estimates or a completed matched comparison.

The initial-prefix catalog's structural limitation was recorded before paid calls:
only documentation/profile/password reads are audited, while authentication remains
a write barrier. No nontrivial family or admitted artifact is established. This
study therefore remains a **NO_GO**, does not change manuscript numerical claims,
and closes none of the matched-compiler, fresh-calibration or learned-gate objections.
The next funded experiment requires meaningful candidate viability, competent
baseline behavior and positive controls through the exact adapter/grader path first.
