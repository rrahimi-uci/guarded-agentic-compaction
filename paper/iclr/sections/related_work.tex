\section{Related Work}
\label{sec:related}

\paragraph{Guarded trace and agent workflow compilation.}
\method adapts the tracing-JIT pattern---compile a hot path behind a guard,
deoptimize on a miss~\citep{bala2000dynamo,holzle1992deopt}---to agents, adding
grounded arguments and declared effects~\citep{lucassen1988effects}. Agent
systems mine workflows, cache plans, compile orchestration, validate plans, or
prune topology
\citep{abuzakuk2026awo,wang2025awm,zhang2025plancache,wei2026evoc2f,winston2026agentjit,li2026flowcompile,chen2026agentslimming};
DSPy optimizes prompts, GEPA evolves them, RouteLLM changes models, LLMCompiler
parallelizes calls
\citep{khattab2024dspy,agrawal2026gepa,ong2025routellm,kim2024llmcompiler}.
Unlike these, \method treats recurrence only as a proposal: provenance, effects,
position, contracts, and finite-sample risk each retain a veto.

\paragraph{Synthesis, risk control, and evaluation.}
Bounded search draws on programming by example, sketching, and provenance
\citep{gulwani2011flashfill,solarlezama2006sketching,cheney2009provenance};
admission combines Clopper--Pearson with fixed-grid learn-then-test
\citep{clopper1934binomial,angelopoulos2022ltt}. BFCL, ToolLLM, and AppWorld
score tool use or interactive agents broadly
\citep{patil2025bfcl,qin2023toolllm,trivedi2024appworld}. NESTFUL and API-Bank
retain observed intermediate results directly; BFCL and AppWorld become compiler
substrates only once gold artifacts run on their pinned backends, and no
provider-free row measures agent quality.
