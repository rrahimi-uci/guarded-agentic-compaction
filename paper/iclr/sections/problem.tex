\section{Problem Formulation}
\label{sec:problem}

\paragraph{Episodes and candidate regions.}
An episode $E=(z,M,e_{1:T},y)$ contains an entry-state snapshot $z$, a
content-addressed execution manifest $M$, ordered events $e_t$ (model requests
and responses, tool calls and results, handoffs, guardrails, approvals, errors,
commit boundaries), and an observable outcome $y$; $c_j$ denotes the $j$-th tool
call and $o_j$ its result. Each tool $f$ carries an
application-owned effect declaration $\epsilon(f)$ and capability flags such as
\emph{speculatable}; an unknown effect is not a read.

A candidate region $R=[a,b]$ begins at a model-request boundary and ends after
a tool result. It is \emph{groundable} when every call argument is either an
application-declared literal for that slot or an expression over entry state
or prior results inside $R$,
\begin{equation}
  \forall c_j \in R,\ \forall u \in \operatorname{args}(c_j):\quad
  \operatorname{Lit}(c_j,u)\ \vee\
  \exists\, s\in\operatorname{Src}(z,o_{<j}),\ \exists\, g_{j,u}\in\mathcal{L}:
  \ u = g_{j,u}(s),
  \label{eq:grounding}
\end{equation}
where $\operatorname{Lit}$ is a schema-level allowlist fixed independently of
the traces, $\mathcal{L}$ is a closed, bounded transform library, and
$\operatorname{Src}(z,o_{<j})$ enumerates the flattened paths of $z$ and of
each prior result $o_i$, $i<j$; and \emph{effect-admissible} when every tool in
$R$ is declared read-only, speculatable, replayable, and inside one principal
and isolation partition. The witness is deliberately \emph{single-source} ---
one chain over one observation, not a join over the history --- which is the
quantifier \cref{alg:patg} implements. Handoffs, approvals, writes, errors, and
unknown effects are hard barriers.
Because the deployed runtime resolves artifacts at the initial model boundary,
the compiler also imposes a \emph{position invariant}:
\begin{equation}
  a = 0 \quad\text{in the normalized model-boundary index.}
  \label{eq:prefix}
\end{equation}
A suffix program dispatched at entry can reorder or duplicate calls the agent
has already made; a pilot that violated \cref{eq:prefix} produced exactly that
fault (\cref{app:pilot}). Everything that follows is therefore an \emph{initial
read-only prefix} compiler; \cref{sec:res-refusal} prices what that costs.

\paragraph{Selective optimization objective.}
The compiler emits an artifact $A=(P,H,V,q,\eta,M)$: a deterministic program,
hard guard, output verifier, nonconformity score, threshold, and manifest pins.
Let $x=(z,M',\omega)$ be a future entry state, runtime manifest, and external
state, where $M'\simeq M$ is equality on every pinned compatibility field and
$\omega$ affects outcomes and cost but is unobservable at the dispatch boundary.
Dispatch is \emph{selective},
\begin{equation}
  d_A(x) = \mathbf{1}\{\,H(z,M')=1 \ \wedge\ q(z)\le\eta
              \ \wedge\ M'\simeq M\,\},
  \label{eq:dispatch}
\end{equation}
and any failed precondition runs the unchanged baseline $B$. If execution fails
before a commit and staging proves the attempt clean, $B$ runs; a dirty failure
after a commit is an incident, not a fallback. Fix $L(A,x)=1$ for an externally
visible task/contract violation or incident after dispatch, $L=0$ for a clean
abort followed by unchanged $B$, and let $C(A,x)$ be the complete realized cost
of the attempt including a clean fallback. For a future group
$G=(x_1,\ldots,x_m)$, set $D_A(G)=\max_i d_A(x_i)$ and $W_A(G)=\max_i
d_A(x_i)L(A,x_i)$. We seek
\begin{equation}
  \max_A\ \
  \mathbb{E}_{G\sim\mathcal{D}_{\mathrm{grp}}}\!\Big[\textstyle\sum_{x\in G}
    d_A(x)\,\{C(B,x)-C(A,x)\}\Big]
  \quad\text{s.t.}\quad
  \Pr_{G\sim\mathcal{D}_{\mathrm{grp}}}\!\left[W_A(G)=1 \mid D_A(G)=1\right]
  \le \alpha .
  \label{eq:objective}
\end{equation}
Both halves take the same group measure $\mathcal{D}_{\mathrm{grp}}$, summing
within a group so that objective and constraint weight groups alike.
\emph{First}, the constraint
conditions on dispatch: abstention does not enter its denominator, although it
earns no savings in the objective; by convention its conditional risk is zero
when population dispatch probability is zero. \emph{Second}, returning \emph{no}
artifact is feasible, so \retire{} is a legitimate output, and
\cref{eq:objective} is a design target rather than a solved program --- the
implementation calibrates a bounded ranked set and retains nondominated
survivors, and we prove neither optimality nor any guarantee for that search
beyond the per-candidate and fixed-$m$ cases of \cref{sec:method}. \emph{Third}, $L$ scores the \emph{episode}: a sound prefix whose baseline
continuation errs still contributes $L=1$, so the gate certifies end-to-end
compliance under substitution, not non-inferiority, and admission requires $B$
to already succeed on a $1-\alpha$ share of the dispatched slice
(\cref{app:limits}).
