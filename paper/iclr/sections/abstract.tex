Tool-using agents often call a language model at every step, even when they
repeat the same read\nobreakdash-only lookups. Replacing that repeated reasoning with a
fixed program could cut cost, but repetition alone does not make it safe: a
tool argument may depend on an earlier result, a ``read-only'' tool may have
side effects, and replaying the same calls may still change the final answer.

We introduce \emph{guarded agentic compaction} (\method), which compiles the
recurring read\nobreakdash-only opening of an agent's workflow into a deterministic
program only when the evidence justifies it, and otherwise leaves the agent
unchanged. \method traces every tool argument to observed data, treats writes,
approvals, handoffs, and unknown effects as hard stops, checks inputs and
outputs at run time, and deploys a program only after enough independent
examples pass a statistical test.

On three real GitHub workflows, the compiled agent matched the original
agent's accuracy (90 of 90 held-out tasks correct, versus 89 of 90) and never
failed a task the original agent solved, while making about two-thirds fewer
model calls, finishing in about a third of the time, and costing less than
half as much per task. On 132 fresh pull requests created after our data
snapshot, it made no end-to-end errors, which bounds its error rate below 2\%
with 90\% confidence for open and merged pull requests. \method also refuses
when evidence is thin: three public tool-use benchmarks contain repeated
workflows but at most 26 examples of any one, against the 92 \method
requires, so it compiles nothing there, while a fourth, AppWorld, has enough
for one small program. On BIRD, a public text-to-SQL benchmark, a live schema-first
agent's opening was compiled on five databases, cutting model calls by 45\% with
no detected accuracy loss; an agent choosing tables per question was refused. With a second model family and a second provider,
\method rediscovers the same programs on two of three workflows and declines
the third. We also report its limits: its main guarantee mostly confirms that
enough examples were seen, the savings hold within one data snapshot, and
when tool outputs were deliberately corrupted its run-time checks prevented
no wrong answers.

\method reframes agent optimization as evidence-gated specialization: compile
only what is justified, and keep the model's reasoning everywhere else.
