Repeated agent workflows can waste model calls, but recurrence alone does not
justify replacing reasoning: arguments depend on observations, tools can have
effects, and identical evidence can yield different answers. We introduce
\emph{guarded agentic compaction} (\method), which compiles recurrent initial
read\nobreakdash-only prefixes into deterministic programs. It requires grounded
arguments, declared effects, input/output contracts, and exact finite-sample
admission under independent-group assumptions; otherwise it retains the agent.
Most certificates concern replay, not final answers.

On three GitHub workflows, compilation satisfies 90/90 held-out contracts
versus 89/90 for the unchanged agent, with 66.6\% fewer model requests.
A separate adapted offline Agent Workflow Memory comparison spans three
workflows, two models, and 1,362 fresh records (8,172 attempted episodes).
Compilation reduces deployment cost by 36.9--79.1\% and model requests by
50--75\%. Five of six comparisons establish a preregistered five-point accuracy
noninferiority margin with multiplicity correction; second-model backlog is
inconclusive. Only two meet a two-point margin. Statistical, support-only, and
deterministic gates route identically, showing no incremental runtime gate benefit.

On BIRD, a schema-first opening compiles on 26/31 databases, with 45--50\%
fewer requests and no detected accuracy loss; question-specific table selection
is refused. NESTFUL and AppWorld show no measured deployment benefit.
A post-cutoff cohort of 132 pull requests has no end-to-end error (upper bound
1.73\% at 90\% confidence). Constructed tasks support request-scope checks;
completeness benefit remains unresolved and earlier drift tests show no
protection. The evidence supports bounded compilation, not universal accuracy
preservation or learned-gate superiority; independence and transport beyond
the evaluated workloads remain assumptions.
