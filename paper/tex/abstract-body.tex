Tool-using agents often repeat the same read-only execution paths while invoking a model
at every tool boundary. Replacing these repeated decisions with deterministic execution
could substantially reduce inference overhead, but recurrence, replay, and workflow-induction signals do not establish that replacing the model is safe: tool
arguments may depend on earlier observations, apparently read-only calls may have effects,
and even perfect tool replay may change the agent's final answer.

We introduce \emph{guarded agentic compaction} (\method), a compile-or-retire system that
specializes recurrent agent execution paths into bounded deterministic programs only when
the evidence supports it. \method requires each candidate to pass a sequence of evidence
gates: tool arguments must be grounded in observable state, effects and execution position
must permit substitution, runtime behavior must satisfy explicit contracts, and
independent calibration must provide sufficient statistical evidence. If any requirement
fails, \method refuses the optimization or falls back to the unchanged agent.

Across three live GitHub workflow families and 90 unseen test cases, \method satisfies the
exact task requirements on all 90 cases while reducing provider requests by 66.6\%, tokens
by 63.1\%, and estimated cost by 58.7\%. A time-forward evaluation across five additional
repositories further demonstrates the intended compile-or-retire behavior: \method
specializes four repositories while refusing to compile the fifth rather than weakening
its evidence requirements. Experiments on four public agent benchmarks reinforce this
boundary: repeated, successfully replayed workflows can still lack sufficient evidence for
safe specialization, and an optimization safe to admit may still be unsuitable for a
particular agent architecture.

Recurrence identifies an opportunity, not a license to remove reasoning. \method replaces
repeated model decisions only when substitution is supported by explicit evidence, with
principled refusal and fallback everywhere else.
