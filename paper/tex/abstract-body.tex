Tool-using agents often repeat a read-only evidence path while paying for a model decision
at every tool boundary. Replacing that path is tempting, but recurrence is not enough: a
later argument may not be recoverable from observed state, a tool may cross an effect
boundary, and a prefix that replays calls correctly may still alter the remaining agent's
answer.

We introduce \emph{guarded agentic compaction} (\method), a trace-to-program compiler for
this substitution decision. It reconstructs typed value provenance, blocks unsafe effects,
synthesizes only bounded read-only prefixes, verifies contracts, and admits an artifact
only after an exact finite-sample risk check. Its normal output is refusal: when the
evidence is incomplete, it must retain the unchanged agent.

Across three live-provider GitHub workflow families, admitted programs preserve all 90
held-out exact contracts with no compiled-only failure while reducing provider requests by
50--75\%. A time-forward extension completes exact held-out pairs on four of five
repositories and retires the fifth. On NESTFUL and API-Bank, recurrent families also
retire because their support cannot meet the configured admission requirement. Hand-written
programs tie the compiler where they occupy the same interface, so the contribution is
automatic discovery and calibrated admission, not a claim of runtime dominance.

The central result is an evidence boundary: traces establish recurrence, not
admissibility. Agent workflow optimizers should be evaluated by what they safely refuse
as well as by what they accelerate.
