% Fonts. arxiv.sty asks for Times by setting \rmdefault to the legacy `ptm'
% family. Under pdfTeX that resolves to Nimbus Roman, but this paper is built
% with Tectonic (XeTeX), where the Type-1 psnfss families have no TU coverage:
% the body silently falls back to Latin Modern and every \textbf/\emph/\textit/
% \textsc renders as upright regular text. newtxtext/newtxmath are the
% maintained Times-compatible replacements and resolve under both engines; the
% embedded body face is TeX Gyre Termes, i.e. Times, exactly as the style
% intends. Loaded after arxiv.sty so it wins the \rmdefault assignment.

% In one column a starred float has no meaning, but LaTeX still routes
% figure*/table* through \@dblfloat, which may only be placed at the top of a
% *later* page. That strands half-empty pages. Map them onto ordinary floats so
% they take part in normal placement while the shared body keeps the starred
% form for the two-column build. arxiv.sty swaps the caption skips for `table'
% so a top caption sits tight against the rule; table* has to be told the same,
% because it reaches \@float through \@dblfloat and misses that redefinition.
\makeatletter
\let\@dblfloat\@float
\let\end@dblfloat\end@float
\@namedef{table*}{%
  \setlength{\abovecaptionskip}{\@belowcaptionskip}%
  \setlength{\belowcaptionskip}{\@abovecaptionskip}%
  \@float{table}}
\@namedef{endtable*}{\end@float}
\makeatother
