# Publication quality assessment

This rubric separates artifact quality from scientific acceptance readiness. Scores use
only checked-in, reproducible evidence; proposed and preflight-only experiments receive no
empirical credit.

| Category | Score / 100 | Evidence-based assessment |
|---|---:|---|
| Technical depth | 95 | Typed traces, value provenance, effect/position barriers, bounded synthesis, exact compiler admission, continuation checking, and a multiplicity-corrected transformation portfolio form a coherent implemented stack |
| Novelty | 82 | The portfolio selects across measured transformation classes under separate exact quality/regret bounds and review-aware deployment, but FlowCompile, AWO, EvoC2F, Agent JIT, GEPA, and the one-family pilot constrain broad claims |
| Clarity | 95 | The paper distinguishes compiler admission from portfolio selection, macro recommendation from synthesis, and prospective single-family evidence from cross-family policy value |
| Writing quality | 92 | Professional narrative with explicit negative evidence; methodology remains dense |
| Experimental rigor | 85 | The 30-group calibration and 12-pair prospective action test add a genuine pre-data intervention to the sealed replication; one domain, a 15% pilot limit, no non-inferiority margin, and no heterogeneous action-optimal families remain limiting |
| Reproducibility | 98 | Pinned datasets, retained native traces, preflight decision, calibration digest, exact commands, recomputation, generated artifacts, and secret checks are unusually strong |
| Presentation | 93 | Shared-source conference/article builds, generated portfolio figure/table, and automated typography/content gates |
| Engineering validity | 97 | Public typed selector API, exact bounds, group de-duplication, compatibility invalidation, review-required macro mode, release checks, and raw-result recomputation are strong |
| Scientific contribution | 88 | Establishes guarded partial compilation, a program-versus-answer boundary, and prospective risk-bounded action selection; it does not yet establish selection value across families or superiority to closer optimizers |

## Verdicts

- **Artifact/manuscript engineering: 96/100.** The artifact is organized, auditable,
  reproducible, and publication quality as a research prototype.
- **Top-tier main-track readiness: 87/100 (major revision).** The expanded paid
  replication and prospective portfolio pilot now implement and test reviewed action
  selection: macro is chosen from 30 groups and passes 12/12 fresh contracts while reducing
  every measured resource. One domain, no action-diverse families, no learned-workflow
  head-to-head, and an all-or-none compiler gate prevent a broad claim.

The 90/100 target is met for artifact quality, not scientific acceptance readiness. A
defensible 90+ main-track score requires a powered multi-domain non-inferiority study, a
non-degenerate post-selection risk--coverage frontier, prospective continuation admission,
multiple workflow families with different optimal actions, and at least one same-task
learned-workflow comparator. GEPA is relevant when residual
prompt evolution is evaluated; it is not a substitute for the macro/compiler baseline.
